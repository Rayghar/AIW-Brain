# Gate 6B.2 epistemic validation specification

Canonical statuses remain:

- `normative-requirement`;
- `source-stated-recommendation`;
- `measured-result`;
- `source-example`;
- `implementation-observation`;
- `expert-interpretation`;
- `sol-inference`;
- `hypothesis`;
- `illustration`;
- `unknown`.

Source-backed statuses require `statementOrigin=source` and the corresponding basis. Normative requirements additionally require an official-specification authority class and binding language in the exact support span. Examples cannot become normative requirements automatically. Sol inferences cannot be represented as source statements. Hypotheses cannot be represented as facts. Expert interpretation requires an actual external-review receipt and is rejected in this delegated development review.

Structured fields carry their own canonical status. Unsupported fields must be marked unknown. The output-level status does not override field-level evidence.
