# Prompt 6G specialist diagnostic roadmap

Each deferred class requires a separately frozen, class-specific diagnostic. Begin with deterministic decomposition, then use 8–16 positive, negative and abstention cases, strict field-level schemas, an inspectable label set, adversarial review and absolute quality gates. Cross-file Genome and reference-architecture work requires governed architecture-group context. Security and modernisation normally require external domain review before authority can advance.
