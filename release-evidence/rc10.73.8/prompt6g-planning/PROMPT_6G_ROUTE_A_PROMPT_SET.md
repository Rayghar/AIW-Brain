# Prompt 6G Route A prompt set

## A1 — source example

Extract only a documented source example. Copy exact support, conditions and limitations. Do not universalise or promote it to a requirement. Return candidate authority only.

## A2 — implementation observation

Extract only directly observed implementation structure or behaviour. Preserve product/version scope and explicit limitations. Do not convert the observation into universal advice. Return candidate authority only.

These prompts are distinct and may not be replaced with a generic semantic prompt.
