# Evidence Timestamp Semantics

Generated by command: 2026-07-15T09:03:30.8617484Z  
Production accepted: **false**

`generatedAt` and labels such as `Generated by command` represent the actual time at which a command generated or refreshed evidence. Shell command receipts retain their actual start and finish times.

`deterministicFixtureTimestamp` and `governanceMigration.migrationEffectiveAt` represent the fixed value `2026-07-15T00:00:00.000Z`. That value exists only to make deterministic governance fixtures and replay tests byte-stable. It is never evidence that a GitHub request, build, browser launch, semantic transformation, or report-generation command executed at that instant.

Playwright's `artifactRecordedAt` values are filesystem evidence-write times. They are actual local observations, but are not asserted as the precise browser-process launch instant.

Authenticated GitHub preflight evidence uses its own actual `generatedAt` value. No deterministic fixture timestamp is used in that live evidence.
