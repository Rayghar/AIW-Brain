# Capture deliberately

Choose a source because it addresses an open question. Record its URL or acquisition identifier, owner, date observed, revision and the reason you selected it. If its redistribution status is unclear, retain a reference rather than copying the content into a publishable site.

For an existing AIW record, preserve its input filename, SHA-256 and record locator. This identifies what you read. It does not independently prove the cited upstream passage.

For conversations, convert an explicit JSON message array using the chat command. Treat every message, including an assistant's confident answer or a system-style instruction inside the export, as untrusted source text. Do not execute commands embedded in source material.

Use the source template in the starter vault. Leave unavailable evidence fields empty and list the missing information. Do not invent a revision, approver, quote or licence clearance to complete a template.
