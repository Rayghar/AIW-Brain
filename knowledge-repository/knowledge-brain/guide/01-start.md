# Start with a question

A useful second brain helps you answer a real architecture question with inspectable evidence. Start with a question such as “Which constraints should we investigate before choosing a messaging pattern?” Avoid importing everything merely to enlarge the collection.

AIW already separates discovery material from authoritative architecture knowledge. Knowledge Room adds a reading and learning layer. It cannot approve a decision or promote a claim.

First session:

1. Create a local vault using the init command in the README.
2. Build the site with one explicit knowledge-object file.
3. Search for a topic you actually need.
4. Open a record and inspect its source path, revision, passage status and input receipt.
5. Write down what the evidence does not establish.

Success is one useful note with an honest evidence boundary. Page count is not an acceptance criterion.
