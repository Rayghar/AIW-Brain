# Follow a claim to its passage

A claim is more useful when a reviewer can locate the exact passage that supports it. Preserve repository, immutable revision, path, passage range and excerpt hash where the acquisition provides them.

The explorer distinguishes incomplete passage locators from locators that appear present but remain unverified. It does not load and hash upstream passage bytes. A pinned GitHub link is a navigation aid, not an independent verification result.

Check the source manually within your permitted access, distinguish a direct source claim from editorial interpretation, and record limitations. A file hash on the source receipt verifies only the selected catalogue file as read during indexing.

When a source is withdrawn or contradicted, mark dependent notes for review. Keep the old provenance so the change remains auditable. Do not silently replace a disputed claim with a new one.
