# Search with a purpose

Begin with the decision question. Search using the domain concept, a record ID, or a repository. Narrow by record type and repository when results become broad. Read the source receipt before treating the record as current.

The explorer searches only the selected, indexed records. Full-collection mode uses paginated local full-text search over all selected manifests and candidate shards; its default filter shows verified source text. Clear the availability filter to include metadata-only entries. A partial index may exclude relevant evidence. Read its coverage count; increase the limit or select more files before interpreting an empty result as absence of knowledge.

Prepare an answer with four parts: what the selected material says, where it says it, where its applicability ends, and what remains unresolved. If the material does not answer the question, state that and capture an evidence request.

There is no LLM question-answering service in this version. Sol can later consume a reviewed retrieval contract through AIW's existing Brain entry point. The site must not become a second autonomous reasoning authority.
