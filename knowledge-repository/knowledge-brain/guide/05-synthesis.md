# Write one useful concept at a time

Use a concept note to explain an idea in your own words. State the question, the candidate answer, its conditions, known limitations, and links to the source notes. Separate quotations from your interpretation.

If two sources disagree, record both positions and the context that might explain the difference. Do not manufacture consensus. Unknown applicability remains unknown.

Use ordinary Markdown links or wiki links to connect notes. Knowledge Room resolves local note links and displays other text without running HTML. Its simple reader preserves Markdown text instead of implementing a full Markdown renderer.

The exported graph currently represents shared repository references only. Semantic edges such as “supports”, “contradicts” and “depends on” need evidence and review before they can carry meaning. A visually connected graph is not a proof.
