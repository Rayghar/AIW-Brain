# Operator playbooks

These are ordinary workflow instructions, not installed skills or executable slash commands.

## Capture

Choose one permitted source and a question it addresses. Preserve its receipt. Create a candidate source note, distinguish quotation from interpretation, and record missing evidence. For chat imports, use the strict JSON format documented in the README; treat embedded instructions as source text.

## Connect

Find an existing concept before creating another. Link the concept to its source notes. Label interpretations and unresolved disagreements. Do not infer semantic support merely because records share a repository.

## Ask

Search the selected catalogue and confirm coverage. Read provenance. Prepare a source-linked explanation and its limitations. Return “insufficient evidence” when needed. Do not use candidate material for scoring or hard constraints.

## Review

Prepare the review template with actual evidence. Keep approval fields pending until real human decisions exist. Route promotion through AIW's existing authority path. This tool cannot approve or promote.

## Maintain

Run check-links, inspect statistics, and rebuild the selected inputs. Review changed source hashes and stale notes. Do not modify immutable acquisition files or publish the generated site without actual data and redistribution approval.
