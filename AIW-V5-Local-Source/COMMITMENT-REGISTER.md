## Product contract

One canonical project graph, eleven chapters, Work / Model / Validate / Output, and a living SDD. Sol develops the design with the architect; Mind Factory compares architectural approaches; Cursor explains selected objects and their evidence. Architecture Journey is ordinary navigation; perspectives occupy their own scrolling region. Assistance and source handling use the existing surfaces.

An assertion, a draft, architect acceptance, independent review and observed production evidence are distinct states. An LLM does not approve a design. Descriptive catalogue entries remain discovery material. Accepted state and frozen baselines are retained when support changes, with current-use warnings and explicit review gates.

## Evidence and deployment gates

- The archive reported 328 Pattern DNA records, one reasoning-ready, zero calibrated scoring records and zero completed live repository refreshes. Those historical declarations are retained, not silently upgraded. Actual permitted repository passages, independent reviewers and benchmark results are still required to certify a broader knowledge release.
- Hosted storage is D1/R2 with service-enforced project/organisation access. It is not the blueprint’s deployed PostgreSQL/pgvector/RLS stack. Semantic retrieval uses the configured embedding provider and bounded in-app comparison.
- Live issue/runtime accounts need owner-scoped server profiles and credentials. Adapter acceptance used controlled provider responses. No customer repository, issue tracker or runtime was connected or altered during this release.
- Token budgets use conservative reservations; unresolved provider failures keep reservations until their rolling window expires. Contact masking is heuristic. Inspect the source packet for information repeated in other records.
- Recovery supports a 12 MB transport envelope, 64 MB expanded project and 7 MB of original source bytes / 200 files. The 1,400-row recovery check ran against the Node/SQLite/R2-compatible local harness; it is not a hosted load benchmark.
- Mathematical quality effects remain calculations with declared assumptions. Reference journeys are authored examples, not measured benchmarks or accepted designs.

## Still outstanding product scope

This release does **not** complete every ambition in the legacy assessment. Diagram/image-to-model ingestion and reconciliation, a continuously synchronized digital twin, autonomous knowledge learning, full API-standard conformance, bidirectional external write-back, unattended scheduled repository refresh and the complete forty-journey / 167-function legacy scope remain unimplemented. These require separate concrete acceptance work; older proposal labels are not evidence of delivery.
