## 1. How the two codebases relate

The two codebases belong to the same product family, but they are separate implementations. Both are "AIW V5" workbenches with the Work / Model / Validate / Output surfaces, Sol, Mind Factory and the Cursor. Both run on the same approved knowledge release AKR-0.10.73.5 (`A/data/approved-knowledge/AKR-0.10.73.5`, `V/public/catalogue-index.js:3`). V5 has already taken content from this exact archive: its candidate set names `AIW_R0_R7_REVIEWER_REPAIRS_FULLSOURCE.zip` as its origin (`V/candidate-sets/bk-p2-20260911.json:2-8`), and its Chapter 4–7 guided design uses 9 of the archive's FPA/MSA "CMP" questions (`V/public/design-planner.js:15-19`). No source file is shared, because the archive is TypeScript and V5 is plain JavaScript.

The archive is a TypeScript npm-workspace monorepo:
- 7 apps, of which the root `build` script builds only `apps/api` (Fastify, 253 top-level modules, about 68k LOC, 69 route-group registrations), `apps/worker` and `apps/web-v5` (React 19, about 46k LOC); the other four web apps are dormant;
- 14 packages;
- PostgreSQL 16 with pgvector, owner and runtime roles, and 60 checksum-manifested migrations with forced row-level security;
- 7 chapters (introduction, drivers, decisions, components, models, refinements, evidence), plus the destinations Project team, Publish, Review and Knowledge, and project branches in every URL;
- per-stage workspace tables with idempotent stage-command journals.

V5 is much smaller:
- a Node server with no runtime npm dependencies (`V/server.js`, 85 lines) that runs the same `worker.js` router (161 lines) as the hosted Cloudflare Worker;
- 8 `*-service.js` modules and 207 browser ES modules in `public/`, about 3.35 MB of which is embedded data or vendor code;
- SQLite locally or D1/R2 when hosted, with 8 drizzle migrations;
- one JSON document per project with revision compare-and-swap;
- 11 chapters, from requirements to Review & Realize.

Honesty status:
- The archive declares `productionAccepted: false` (`A/RELEASE_MANIFEST.json`), with 21 of its 34 gap-register findings verified, 11 partial and 1 blocked (durable database).
- V5 calls itself v20.6 in `V/README.md:3`, but its `package.json` says `1.0.0` and it has no release manifest.

## 3. Recommended top 10 to port, in order
