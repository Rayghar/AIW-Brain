## Summary

1. Tenant and role boundaries hold under live probing: a non-member gets 404 on every project route, an editor cannot change roles or lifecycle, a viewer cannot write; the actor header cannot be spoofed past the session cookie; revision compare-and-swap and idempotency receipts behave as documented.
2. The four-eyes approval rule can be satisfied by identities carried in a restore package: a restored baseline whose architect review names `alice-imported` let the restoring account record `Approved` governance evidence (GV-001, actor=local-architect, reviewAuthor=alice-imported). Restore neutralises knowledge receipts and organisation pins but not `finalReview` review/baseline/governance actors (B2-01).
3. The local server buffers any request body in full before any size check: a 200 MB POST took resident memory from 138 MB to 1,154 MB and was refused only afterwards; a visited web page can trigger this without passing the Origin check (B2-02).
4. Every requirement or model edit rewrites the whole change journal to a new blob and never deletes the old one: 10 edits produced 10 blobs and 705,766 bytes; the journal is also embedded in every project read, which grew from 264,431 to 396,533 bytes over those 10 edits (B2-03). No retention job exists for runs, events, packets, indexes or uploads (B2-04).
5. The command endpoint validates `type` but not `payload`; a string payload was applied and blanked the brief (B2-05). Integrity faults (missing journal blob) are answered as a transient 503 "could not reach project storage" (B2-06).
6. `AIW_LOCAL_DB` moves the SQLite file but blobs always go to `.aiw-local/baselines` under the process working directory; a backup of `project.sqlite` alone is unreadable afterwards (B2-07).
7. Viewers and reviewers can bulk-export the whole project, attachments, reviews, discussions and activity via `/api/recovery?action=export` (no role gate on that handler) (B2-08). Workbook imports by an editor are attributed to the owner (B2-10).
8. The provider adapter is sound on validation and grounding but has no retry, no streaming and no cost figure; a run interrupted mid-flight keeps its 188k-token reservation in the daily budget for 24 h (B2-11).
9. Operability: no health endpoint, no shutdown handler, no explicit request timeouts, unstructured error logs, unbounded compression cache, 13 of 20 environment variables absent from `.env.example` (B2-13, B2-14). Nine backend modules have no importing suite; syntax checks skip `repository-service/` and `scripts/` (B2-16).
10. The packaged Worker embeds every client asset in one 7.07 MB module (1.90 MB gzip); API JSON is never compressed and every command returns the full document (B2-15, B2-17).
