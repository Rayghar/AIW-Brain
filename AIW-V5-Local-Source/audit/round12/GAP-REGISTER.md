## Purpose

This is the one register of what AIW could not do, did poorly or lost when it took the SEABaaS workbook (1,400 requirements in 18 modules) to a Solution Design Document. It merges about 550 candidate findings from four sources: the eight review dimensions of round 12, the running register of the exercise, the readers of the first understanding pass and the gaps met while drafting the design through governed commands. Each entry was checked against the code at `52dda8a`, given one verdict and one owner, and a test that shows when it is done. The remaining workstreams implement it and are audited against it. It holds AIW gaps and improvements only; client material stays out of the repository.

## How to read it

Ids are `GR-<area>-nn`, numbered within an area: running and open work first, then external, closed and rejected, each by severity. Severity is judged against the aim of a governed workbench that produces an SDD like the reference for a project of this size: a blocker stops that aim, a major gap weakens it, a minor gap is a flaw, and an improvement is not a defect. Status is running (a running workstream has it in its brief), open (assigned, not started, or in a running workstream's files but not in its brief), external (only a person or outside access can close it), closed (a merged commit closed it) or rejected (not a defect, with the reason). Sources keep every candidate id: the reviewers' own ids (`BD-` banking, `GP-` governance, `F-` intake, `SDD-` document, `T-` traceability, `DM-` data model, `PS-` performance, `UX-` screens; `-R-` marks a refuted candidate; `IF-S-`, `SB-` and `SD-T1` are source-data findings), the running register's `G-nn` and `S-nn`, and `all-gaps#n` and `design-gaps#n`, 0-based like the reviewers' `An` and `Dn`. The JSON (`gap-register.json`) adds the verdict, the evidence (file:line at `52dda8a`, or a probe file in the session scratchpad, marked `scratch`, which is not committed), the detail and the recommendation; the work orders hold the same per owner. Acceptance names the suite that checks it; suites marked new below are proposed names the owner may change.
