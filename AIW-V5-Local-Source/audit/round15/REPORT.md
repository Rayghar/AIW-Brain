This report covers the local source candidate derived from the supplied Round 14 source. It records UI and diagram changes tested against the reference projects. It is not a hosted release or an architectural quality acceptance; `productionAccepted` remains false.

## Open gates and scope

1. The existing strict Chapter 5 full Layers layout time gate is still open: the final local `test:notation-layout` measured **1,300 ms** against **900 ms**. Routing experiments that lowered this time added fallback routes or worsened other diagrams, so the general router was not weakened. The default overview avoids making readers wait for the full dense drawing on first entry, but **Show every element** can still invoke it.
2. The historical Round 11 corridor evidence compares all diagrams byte for byte with an older Chapter 7 Tree default and older generated document fixtures. It is preserved unchanged. A fresh harness run on the current source held structural rules, but it is not interchangeable with that historical comparison. Its existing provenance gate therefore reports stale source hashes after the targeted Chapter 7 and folded-overview changes.
3. This round changes presentation and exploration. It does not fill missing SDD substance, judge architecture decisions, test a real provider or deploy the private site.
