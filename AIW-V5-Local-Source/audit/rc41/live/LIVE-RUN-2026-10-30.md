## Found in the live runs during the fixes, and fixed
- **The journey lost good answers because of one bad one.** A first run on the merged fixes offered no journey answers. The new gap
  guard refused "owner: Unassigned", and the chapter-level verdict withheld six sound acceptance criteria with it. Now an answer that
  restates its open question is left open and recorded (`leftOpen`); every other issue still withholds the chapter (`ec8137b`).
- **An open field invited invention.** A second run accepted an invented Chapter 7 operations plan ("the designated operations
  team…, existing telemetry…") whose own basis said ownership is unassigned. The open-field instruction had moved Sol from restating
  the gap to fabricating an answer. Now a value whose basis says the sources leave the question open is withheld, and the prompt and
  check say so (`sol-field-5`, `acb6a25`).

  model; repeat runs to measure).

  "…, ensuring the core constraint is respected" (Chapter 3) still pass the guard and the check. The review found this gap real but
  refuted its proposed fix; it needs a better rule.
