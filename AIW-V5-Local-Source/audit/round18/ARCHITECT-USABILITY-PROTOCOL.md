# Architecture Brain pilot: independent usability assessment

Use this protocol with an architect who did not build the case. Record actual actions and times; do not fill in a result from an AIW suggestion. The source project, scenario targets, and source-use permissions are confirmed by the project owner before the session. The observer does not coach navigation.

## Tasks

1. Start with a new payment project and a permitted source original. Find the one to three confirmed requirements chosen for the case. State the stimulus, conditions, response, and measurement for its reliability or scalability scenario.
2. Find the component library and identify the application responsibility for payment submission, the logical capability that it needs, and the deployment boundary. Explain which records are project decisions and which are catalogue examples.
3. Find PostgreSQL and Kafka in Technology choices. For a relevant capability, compare two options and explain *why* each was considered, the recorded preference, operating model, version or tier assumption, source and evidence status, and an unresolved obligation. Do not infer that a product is selected from a weighted lean.
4. Change a reliability or scalability target in a disposable copy of the project. Identify the affected quality scenario, decision, technology comparison, operating obligation, and test plan. Say whether the displayed impact is a reasoned inference or a measured outcome.
5. Open the focused Chapter 11 case. Follow a selected requirement to its driver, decision, component, product realization, deployment and observation. Export the case dossier and the working SDD separately. Explain the difference between independent case support and whole-project approval.
6. Close and reopen the project, resume the last chapter, and complete a working SDD export from the same project. Check that the downloaded document belongs to that project and does not claim approval.

## Independent case judgement

The second authenticated architect reviews all six Chapter 11 dimensions against the current case basis, cites the exact source or observation, and records **support** or **rework** with limits. The case can be reviewed with an incomplete SDD; formal SDD and governance approval remain separate. No synthetic test identity or offline script substitutes for this judgement.
