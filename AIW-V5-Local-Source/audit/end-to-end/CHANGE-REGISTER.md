## Observed failures and fixes

- Product comparison admitted a mismatched typed claim: reproduced with a synthetic 4.1/three-node claim and a 4.0/single-node option; shared scope reader now excludes it.
- Withdrawing linked knowledge left selected reasoning current: the realization snapshot and current eligibility check now mark it stale.
- Release-qualified exclusions failed before semantic embedding, and an indirect architecture packet retained excluded support: fixed at corpus filtering and packet assembly; regressions assert the private sentence is never embedded and indirect support is refused.
- Structured source authoring omitted its permission field: added and tested through the mounted UI and Worker, with a second synthetic actor only inside test fixtures.
- Mobile product names existed only as pseudo-content: changed to real accessible text and tested in Chromium.
- Exact-source dialog resolves and verifies canonical originals and returns keyboard focus; hash tampering is rejected.
- The new implementation measured 2,878,960 B of chapter-route code and 756,092 B CSS. The production build correctly rejected the old bounds. Explicit next-whole-KB bounds are now 2,879,488 B and 756,736 B (4 KB and 1 KB increases); size gates remain enabled. The subsequent build passed.
- Walkthrough assertions were corrected to canonical `object` URLs, native export-menu controls and manual tab activation (arrows move focus; Enter activates). These were test-contract corrections, not product failures.
- The Windows Sites packager initially interpreted `C:` as a remote tar destination. The installed Git Bash plus GNU tar's documented `TAR_OPTIONS=--force-local` handles local drive paths, without editing protected helpers or bypassing a network restriction.
- A further real Chromium focused-case walkthrough reproduced a Back-navigation defect: returning to a Chapter 11 case URL without an explicit `validate` value restored the remembered model-integrity lens. The shell now recognizes that URL as a focused-case destination before consulting remembered state. Explicit SDD/model links retain precedence. The browser regression checks the exact requirement inspector, case/model/SDD switches, Back, focus, deep links and phone layout.
- Expanded Windows browser runs found SQLite teardown racing process exit in the payment and focused-case suites. Both now await the owned server's exit before deleting its scratch database. Sol's context-preview assertion and the focused-case header assertion were updated to the current UI contract. Initial failures and the route diagnostic are retained with the subsequent passing results.
