# Source media: global product correction

## Product language

Design Resources → Knowledge Repository → **Source media** is the section name. It is a general way to discover timecoded source material. **Candidate · unreviewed**, rights restrictions, and release state belong to the individual record. They are not names for a global capability. Copy, route, empty states, filters and screen reader announcements follow this distinction.

## Data boundary

The preceding source version embedded a private candidate scene catalogue in `public/video-knowledge-candidates.js`. That was an inappropriate distribution boundary. The browser projection and its generator were removed. A signed-in member of an existing project now requests source media from the AIW Worker's `view=video-status` and `view=video` routes. The Worker resolves the project under its authenticated owner, sends that tenant identity to the repository service, and the service requires both a valid bearer token and an explicit tenant allow-list. No query-supplied tenant identity is trusted. The service keeps the imported metadata separate from verified source revisions, released claims and Sol packets.

An unconfigured, unreachable or empty repository presents a truthful empty or unavailable state. The private hosted Site cannot contact the repository service on a laptop's loopback interface; it requires an independently configured reachable private repository service before source media can appear there. No browser fallback or bundled copy is used. The timecoded index is an interpretation and does not supply the recordings, verified transcripts, permission to redistribute them or approved architecture knowledge.

The current import command remains an exact-pack adapter for the earlier six-file engineering pack. The shared interface and authorized reading are reusable, but a general customer media ingest contract has not yet been built. A global ingest flow must handle each tenant's permitted originals, rights, schema version, source integrity and review lifecycle rather than treating this pack as a universal format.

## Interaction

The reading keeps source locator and time/frame spans, filters, related concepts and relationships, a copy action, a shareable project route and a handoff to Sources. It does not direct the architect to apply an unreviewed scene as a chapter decision. Any future action that creates design authority must go through permitted original retrieval, independent review, signed release and contextual assessment against the project's quality drivers.
