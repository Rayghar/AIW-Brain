## Precise boundaries

The software integration is broader than the previous eight-record pilot. It does **not** make 328 catalogue entries production-verified knowledge. The supplied acquisition journals lack their original object-store file bodies; a live read or an exact recorded original is required before interpretation review. No real project claim, licence clearance, independent reviewer or production outcome has been fabricated or automatically approved.

The hosted Explorer uses D1/R2 and HTTP provider calls. This is a port of the recovered authority and retrieval contracts, not a deployment of the original PostgreSQL/pgvector or Node services. Semantic search now works in this runtime without claiming a pgvector connection. It is bounded to this private workbench's method and project-claim corpus, not an enterprise-scale repository search service.

The implemented composition recipes remain interaction, reads and persistence, plus the existing boundary, exchange and protection flows. Other catalogue concepts can be explored and compared with their source posture visible; importing a descriptor does not authorize arbitrary topology generation. Numerical quality calibration and full-corpus independent architectural evaluation remain evidence work.

The browser connection timed out on tab discovery during this delivery. Mounted interface/server acceptance passed, but rendered layout, screen-reader behaviour and a live browser walkthrough have not been certified.
