Version: v0.10.0-rc.10.17  
Sprint: 8.9.4

## Tier doctrine

Essential sells governed judgment. Professional sells language assistance. Enterprise sells governance and live evidence. Sovereign sells zero-egress control.

The tiers must not create separate minds. All tiers share the deterministic kernel, knowledge-release format, evidence model and human-approval semantics.

## Upgrade semantics

Upgrading increases convenience, governance, live evidence and language capability. It must not change architectural truth without a knowledge-release change.

## Tier gates

Tier gates should be expressed through feature flags, tenant settings and RBAC permissions. The implementation must not fork the kernel or duplicate knowledge-release structures.


## Essential promise

Essential provides governed architecture judgment that works offline. It includes the deterministic kernel, pinned knowledge release, guided journey, Review Studio and SDD/handoff export.
