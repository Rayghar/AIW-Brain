# rc.10.72.1 Known Limitations

## Product experience still open

1. Review & Assurance remains a long report-like page and still needs the planned queue/detail/disposition reconstruction.
2. Sol Draft, Sol Next and Ask Sol are not yet consolidated into one user-facing interaction control.
3. Edge routing is not obstacle-aware; dense graphs can still produce crossing relationship labels after arrangement.
4. Smart layout has not yet been accepted at 1,500 nodes and 5,000 relationships.
5. Physical Technology needs a more distinct region/zone/failure-domain visual grammar.
6. Architecture Composition ranking still needs stronger journey-force and quality-tactic calibration.
7. Quality Driver recommendations can still appear too authoritative before measurable scenarios are accepted.

## Verification boundaries

1. Focused Chromium desktop and laptop acceptance passed. Edge, Firefox and WebKit acceptance remains open.
2. Keyboard-only, screen-reader, WCAG 2.2 AA and 200% zoom acceptance remain open.
3. The inherited rc.10.66/rc.10.67 laptop test files did not terminate in this environment; desktop tests passed and the new rc.10.72.1 laptop journey passed.
4. The product shell and artifact-generation chunks remain large and need further code splitting.
5. Live OpenAI/provider acceptance was not required for the deterministic layout and navigation release and was not rerun.

## Enterprise boundaries

Enterprise KMS, remote GitHub, managed identity, PostgreSQL/RLS, queues, object storage, telemetry, backup/restore, worker recovery, external expert review and a controlled enterprise pilot remain externally gated. `productionAccepted` is false.
