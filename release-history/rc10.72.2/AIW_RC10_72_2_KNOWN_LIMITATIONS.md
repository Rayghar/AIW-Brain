# rc.10.72.2 Known Limitations

1. **Live LLM quality was not rerun in the final packaging environment.** The environment had no backend `.env`; final browser evidence used the governed deterministic path. Provider routing and authority controls remain implemented.
2. **The clean-project architecture is intentionally small.** It proves lifecycle continuity and governed mutation, not a complete production agency-banking architecture.
3. **Review approval was not fabricated.** SDD generation remains locked until an accountable review baseline is approved.
4. **Independent human expert validation remains open.** The internal benchmark and AI review do not replace a blinded external panel.
5. **Enterprise trust remains blocked.** Organization-owned KMS signing, remote GitHub acceptance, managed PostgreSQL/RLS, identity, queues, object storage, telemetry, backup/restore and worker recovery still need real-environment evidence.
6. **Browser/accessibility coverage is incomplete.** Desktop and laptop Chromium passed; Edge, Firefox, WebKit, screen readers, keyboard-only completeness, 200% zoom and full WCAG 2.2 AA remain open.
7. **Large-model performance remains unproven.** The target of 1,500 nodes and 5,000 relationships has not completed acceptance.
8. **Canvas routing is not obstacle-aware.** Smart arrangement improves positions, but advanced orthogonal routing, edge bundling and large compound containment need further refinement.
9. **The product shell and artifact-generation bundles remain large.** The final build reports approximately 650.65 kB for the product shell and 1,615.06 kB for artifact core before gzip.
10. **Dialogue memory is still bounded.** Sol history exists, but long-running architectural-decision continuity needs deeper evaluation.
11. **Pattern and domain calibration are incomplete.** Governed recommendations can still be too generic or skeletal for specialised banking architecture without richer evidence and calibration.
12. **Six superseded UI browser contracts are retired.** They remain in release history, but are not active because they require obsolete product identities. Their useful behavioural intent is covered by the rc.10.72.2 suites.
13. **A repeated aggregate backend regression command did not terminate cleanly.** The recovery-specific tests, authority gates and earlier 30-test regression passed, but no second complete final 30-test run is claimed.
14. **Production acceptance remains false.**
